How I built it

  1. Profiled the data: 1,048,575 transactions; fraud only in TRANSFER and CASH_OUT.
  2. Built the charts from grouped aggregations in SQL and pandas.
  3. Checked every column for leakage before modelling, and split train and test by time.
  4. Trained XGBoost with class weighting for the rare fraud class (no hyperparameter search), and compared it with a leaky model and a minimal one.
  5. Exported the trees so the model scores in the browser, matching XGBoost to 6 decimal places.
  6. Built a Streamlit app where a small LLM on Groq writes read-only SQL from plain-English questions and answers them.
SQL: fraud rate by transaction type 
SELECT type,
       COUNT(*)                     AS transactions,
       SUM(isFraud)                 AS fraud_cases,
       ROUND(AVG(isFraud) * 100, 3) AS fraud_rate_pct
FROM transactions
GROUP BY type
ORDER BY fraud_cases DESC;
SQL: frauds that empty the sender's account 
SELECT isFraud,
       AVG(CASE WHEN amount = oldbalanceOrg
                 AND amount > 0 THEN 1.0 ELSE 0 END) AS share_draining
FROM transactions
WHERE type IN ('TRANSFER', 'CASH_OUT')
GROUP BY isFraud;
Python: leakage-safe features and time split 
SAFE = ["is_transfer", "amount", "oldbalanceOrg",
        "oldbalanceDest", "hour"]           # nothing known only after approval
df["hour"] = df.step % 24
train = df[df.step < 300]                  # earlier hours
test  = df[df.step >= 300]                 # later, unseen hours
model = XGBClassifier(n_estimators=200, max_depth=4,
                      scale_pos_weight=neg / pos)
model.fit(train[SAFE], train.isFraud)
