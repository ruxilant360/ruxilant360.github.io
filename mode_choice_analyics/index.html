Checking the numbers before publishing

My first draft said private vehicles carry 96% of trips. The raw file is NHTS 2017, but the mode names in my cleaned file came from the 2022 codebook, and the two surveys number modes differently. Joining back to the raw trip file fixed the labels and brought in the survey weights.

"After the fix" is weighted with the NHTS trip weight, as official figures are.

Trip purpose had the same problem, so the purpose chart uses the survey's own summary purpose (WHYTRP1S).

How I built it

  1. Clean and merge. Joined the NHTS 2017 trip, person, household and vehicle tables and kept respondents aged 16+ with valid answers: 817,981 trips.
  2. Validate. Mode labels looked wrong (a "car" trip with a 2 mph median). Joined back to the raw trip file on household, person, minutes, miles and trip order; all 817,981 rows matched.
  3. Weight. Every share uses the trip weight WTTRDFIN, so each survey trip counts for the U.S. trips it represents.
  4. Group modes. Private vehicle = car, SUV, van, pickup. Transit = public bus, paratransit, city-to-city bus, commuter rail, subway/light rail.
  5. Publish. build_report_data.py writes the aggregates to data.js; this page draws them with Chart.js.

Raw data: NHTS 2017, Federal Highway Administration. Script: build_report_data.py.
